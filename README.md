# Chanlo downloads

Downloads for [Chanlo](https://chanlo.app), the IPTV player for Android TV, Google TV,
phones, tablets and Windows.

This repository holds nothing but the installers published under
[Releases](https://github.com/puzantyac/chanlo-downloads/releases). Chanlo's source
code is not here.

- **Windows 10 and 11 (64-bit)** — download the `.exe` from the latest release.
  Windows may say the publisher isn't verified: choose **More info**, then **Run anyway**.
- **Android TV, Google TV, phones and tablets** —
  [Google Play](https://play.google.com/store/apps/details?id=net.zonecloud.chanlo).

Chanlo is a media player. It doesn't provide, sell or host any channels, playlists or
media, and isn't affiliated with any content provider.
